Glossary

Public vocabulary for the demo. Internal process dumps stay off this site.

Phishing
Email fraud. IMAP / OAuth ingest. Policy then ML.
Smishing
SMS fraud. Best real-time path: iOS Message Filter on-device.
Vishing
Voice fraud. Pre-ring number only: Call Directory + reputation. No SIP / Twilio product track.
Signal Deck
Operator console. Brass + forest. Jinja + hand CSS/JS. No purple, no emoji UI, no npm.
auth_pass
SPF/DKIM/DMARC aligned pass. Required for every known-good domain, including banks.
FPR
False positive rate — safe mail wrongly flagged. Gate budget, not a vanity score.
Golden eval
Held-out labeled set the model was not trained on. CI fails if accuracy / FPR / pump-fake recall regress.
Fail open
Vendor / OSINT errors never block a verdict. Missing IPQS does not freeze triage.
Call Directory
iOS extension that labels or silences numbers before ring. Apple does not send carrier Recents to third-party apps.
Message Filter
iOS SMS filter extension. True on-device RTI for smish.
