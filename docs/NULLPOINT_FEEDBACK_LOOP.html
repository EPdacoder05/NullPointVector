The loop in one picture
ingest / screen → predict (live champion model) → show in Inbox / Quarantine / Call log → human grades: Mark Safe | Block | Needs review → Postgres label saved (0 / 1 / NULL) → feedback.jsonl append (durable buffer) → ephemeral partial_fit (toast Δw — this process only) → nightly ChannelTrainer folds buffer → golden gate (acc / FPR / recall) → GATE PASS → promote new champion → GATE FAIL → keep old champion (no silent drift)
Fifth-grader English
What is NullPoint?
NullPoint
Imagine a smart mailbox + phone guard that reads scary messages and says “safe” or “danger.” When a grown-up marks something right or wrong, the guard studies that homework at night and gets better — but only if the new homework test score is good enough.
Why not change forever on one click?
Anti-poison
If one wrong mark permanently rewired the guard, a joke click or a bad guy could break it. So one click nudges memory for today; the real report card happens at night with a full test.
Operator English — the two layers
1. Ephemeral nudge
Live process
Mark Safe / Block runs one SGD (Stochastic Gradient Descent) step via partial_fit. Toast shows Δw (weight deltas) on TF-IDF (Term Frequency–Inverse Document Frequency) word features. Lives only in the running app process. Restart or gated retrain discards it.
Do: trust the toast as proof the wire works — not as the production champion.
2. Durable champion
Gated retrain
scripts/nightly_retrain.py + ChannelTrainer folds feedback.jsonl + seed data, trains a candidate, runs the golden held-out eval. Only GATE PASS promotes the on-disk model.
Do: run nightly (or on demand before demos). Check /app/benchmarks snapshot.
Why not partial_fit as production?
Tradeoff
One bad seed can skew a single-step update. Nightly evaluates all facts together against fixed metrics (accuracy, precision, recall, FPR — False Positive Rate). That is the anti-drift path investors and auditors want.
Homework every night with a test beats changing the answer key after every worksheet.
Recommended: keep ephemeral nudge for UX; durable path = nightly gated retrain. Weekly benchmark history for audits.
Metrics (what the gate cares about)
Accuracy
Share of predictions that match the golden labels.
Precision
Of items we called threats, how many really were. High precision = fewer false alarms.
Recall
Of real threats, how many we caught. High recall = fewer misses.
FPR
False Positive Rate — safe mail/SMS/calls wrongly flagged. This is the “annoyed user” metric.
Weights / Δw
Logistic / SGD coefficients on bag-of-words features. Positive Δ toward threat on Block; toward safe on Mark Safe. Fixed TF-IDF vocabulary: brand-new scam slang may need a full retrain to enter the vocab.
Benchmark Deck vs external lists
Signal Deck /app/benchmarks
Same harness as CI: held-out golden sets per channel + optional latency. Snapshot file data/benchmark_snapshot.json refreshed by scripts/refresh_benchmarks.py (off the request path — avoids OOM/502).
Weekly: scripts/weekly_benchmarks.py refreshes + appends history for auditor diffs (better than a vanity leaderboard).
vs benchmarklist.com
External sites are marketing tables. Ours are your champions on your golden sets with a promote/fail gate. External auditors should compare gate metrics + history JSONL, not a scraped leaderboard.
Ingest: streamful vs batch
Phishing today
yahoo_stream_monitor polls IMAP every ~5 minutes in batches, then ML per message. That is near-real-time, not true push. Threat scoring still runs per email once fetched.
Next: IMAP IDLE (or provider push/webhook) for second-scale arrival; keep per-message predict (already streamful once fetched).
Smishing / Vishing
Designed as event streams (Message Filter / Call Directory + screen API). Apple does not give carrier call webhooks; directory sync + Live Caller ID Lookup (iOS 18+) is the platform path.
Advanced / “quantum” layer (still classical ML)
Embeddings
Optional
Sentence-transformer vectors map meaning into space so similar scams cluster. Hot path remains TF-IDF + calibrated SGD — transformers/LLMs are assist/explain, never sole enforcement (locked).
Golden gate
Promotion is a constrained optimization: maximize catch rate subject to FPR budget on held-out pump_fake / known-good sets. Fail-closed on gate = keep last good champion.
Acronyms used in this doc
IPS
Intrusion Prevention System — classic signature/block tools. NullPoint adds learned content inference.
SGD
Stochastic Gradient Descent — how weights move one sample (or mini-batch) at a time.
TF-IDF
Term Frequency–Inverse Document Frequency — word importance features for the classifier.
FPR
False Positive Rate — safe items wrongly called threats.
IMAP
Internet Message Access Protocol — how we fetch mail (OAuth or app password).
CID / TFN
Caller ID / Toll-Free Number — spoofed CID vs real campaign callbacks in vishing.
